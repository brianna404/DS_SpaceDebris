Für den Zugang zu space-track.org muss ein Account unter https://www.space-track.org/auth/createAccount angelegt werden. 
Anschließend muss eine Datei mit Credentials namens "DS_SpaceTrackCredentials.txt" erstellt werden. Der Nutzername steht in Zeile 1 und das Passwort in Zeile 2.

Es sind alle Notebooks unabhängig voneinander ausführbar, wenn die Ausgangsdaten anfangs aus der passenden .csv Datei vorher importiert werden. 

Wenn man die Modelle aus ML1 in VS Code analysiert/evaluiert, werden einem die entsprechenden Auswertungen angezeigt, die i Preview auf github nicht sichtbar sind.
